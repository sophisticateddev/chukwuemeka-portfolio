# About these stories

This is the component workshop for [chukwuemekaiheonye.com](https://chukwuemekaiheonye.com). Each component is shown on its own, in light and dark, with normal and reduced motion, in English and French (use the toolbar above).

Use the toolbar to switch theme, motion and language. The **Accessibility** panel runs axe on each story.
